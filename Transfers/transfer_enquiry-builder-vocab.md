## Three-level vocabulary architecture

This is the key design decision confirmed this session. Claude generates all three lists when building an MTP — they are **not** manually filled. They have natural overlap but serve distinct purposes:

| Level | MTP location | Count | Output | Purpose |
|-------|-------------|-------|--------|---------|
| Top-10 poster | `mtp.vocabulary[]` | 10 | `Vocab_Poster.html` (A3 landscape) | Fundamental words for less confident learners |
| KO vocab | `mtp.ko.vocabulary[]` | ~10–15 | `KO.pdf` | Comprehensive, for everyone on the knowledge organiser |
| Lesson vocab | `mtp.lessons[n].vocabulary[]` | ~5 | Animated vocab slide in lesson PPTX | Words specific to that particular lesson |

Each list is generated by Claude when the MTP is first written, choosing words appropriate to the purpose of each list. The builder scripts consume them without any enforcement of overlap/difference.

## MTP JSON top-level structure (england_brazil_mtp.json as reference)

```json
{
  "topic": "...",
  "key_question": "...",
  "challenge": "...",
  "year_group": "Y4",
  "vocabulary": [          ← top-10 poster words
    { "word": "...", "definition": "...", "image": "vocab_geo_xxx.png" }
  ],
  "ko": {                  ← knowledge organiser data
    "key_facts": [],
    "key_skills": [],
    "vocabulary": [["word", "definition"], ...]
  },
  "resources": [...],      ← sort cards, word cards, statement sort, writing mat
  "lessons": [
    {
      "lesson_number": 1,
      "vocabulary": [      ← lesson-level (~5 words)
        { "word": "...", "definition": "..." }
      ],
      ...
    }
  ]
}
```

## Vocab poster details

- **Output:** A3 landscape HTML (`@page { size: A3 landscape; margin: 0 }`)
- **Layout:** 5×2 grid of cards, each card: word (Fredoka One) + image + definition
- **Colours:** `YG_COLOUR = {'Y3':'#c0157b','Y4':'#1798d3','Y5':'#e57d24','Y6':'#2bae62'}`
- **Images:** `file:///Users/innes/Pictures/claude-images/vocab_geo_{slug}.png` (same Mac path pattern as the rest of the system)
- **Fallback:** `<div class="img-placeholder">` if no image found
- **Safe to import:** uses `if __name__ == '__main__'`
- **Main function:** `build_vocab_poster(mtp_or_path, out_path, images_dir=None)`
